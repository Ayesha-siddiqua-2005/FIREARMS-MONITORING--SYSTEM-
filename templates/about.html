ℹ About SENTINEL AI

Project overview, AI pipeline, technology stack, and the team behind it.

🏙️

Mission

To make urban environments safer by providing intelligent, real-time surveillance analytics that empower law enforcement with actionable threat intelligence. SENTINEL AI aims to reduce firearm-related incidents through early detection and rapid response.

🎯

What It Does

Detects firearms in real-time video and images using a Faster R-CNN + EfficientDet ensemble fused with Weighted Box Fusion (WBF) — achieving 97%+ accuracy and <50ms latency.

⚡

Key Features

  • Real-time firearm detection ensemble
  • Image & video upload analysis
  • Interactive crime map (Leaflet.js)
  • Analytics dashboard (Chart.js)
  • Voice alert system (Web Speech API)
  • Dark / Light tactical themes
🛠️

Tech Stack

  • AI: Faster R-CNN, EfficientDet, WBF
  • ML: PyTorch, TensorFlow, OpenCV
  • Frontend: HTML5, CSS3, JavaScript
  • Viz: Chart.js, Leaflet.js
  • Design: Glassmorphism Tactical UI
  • Fonts: Inter, JetBrains Mono
