📖 User Guide

Step-by-step instructions for operating the SENTINEL AI firearm detection platform.

1

System Overview

SENTINEL AI is an AI-powered firearm detection platform designed for smart city surveillance. It uses Faster R-CNN and EfficientDet deep learning to identify firearms in real-time video feeds and images.

2

Image Detection

Navigate to the Detection page. Upload an image by dragging it onto the upload zone or clicking to browse. Click "Analyze Image" to run detection. Results show bounding boxes and confidence scores.

3

Live Monitoring

Go to Monitoring and click "Start" to begin webcam surveillance. The AI analyzes each frame for firearms. The threat ring indicates current safety status: green (safe), yellow (warning), red (critical).

4

Crime Map

The Crime Map page shows an interactive Leaflet map with markers for reported incidents. Markers are color-coded by severity: red for high, orange for medium, and green for resolved.

5

Alert Log

The Alerts page provides a real-time log of all detection events. Each entry includes timestamp, zone, camera ID, detected object type, confidence level, and severity status.

6

Analytics Dashboard

The Analytics page features four interactive charts: weekly detection trends, threat type distribution, system usage, and hourly activity patterns. Statistics update in real-time.

7

Best Practices

For optimal results: ensure good lighting on camera feeds, use a stable internet connection, regularly check analytics for patterns, and configure voice alerts for immediate threat notification.
